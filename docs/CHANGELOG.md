# 变更记录

## 1.0.5

- 计算页新增按银行配置的手续费：支持百分比、元/克、元/笔三种口径，配置一次后买入成本、卖出回款、持仓估值、日报与组合盈亏提醒都会自动扣掉。默认按已核实的银行费率预填，记录单价已含点差时把该行费用改成 0 即可。

## 1.0.4

- macOS 菜单栏的下跌三角换成更亮的系统绿，深色菜单栏上更容易辨认。
- Windows 悬浮球最小缩放从 60% 放宽到 40%。
- 计算页支持多银行持仓：每笔记录绑定银行，各银行按自己的实时卖出价估值，列表分银行展示持仓/成本/浮盈并给出合计；卖出与删除校验也改为按银行独立判断。旧的未绑定记录会自动归到当前主显银行。
- 新增组合持仓盈亏提醒：可设浮盈/浮亏的金额与百分比阈值，按上升沿触发并带冷却；缺价时不会拿不完整的合计误报。
- 分时图新增 7 天与 10 天范围，横轴自动换成日期，悬停提示带日期；跨夜与周末按采样空档断线。
- 新增飞书、钉钉、企业微信、Telegram 机器人推送预设：飞书/钉钉/企微按各自载荷发送，钉钉支持加签；Telegram 使用 bot token 与 chat id。业务错误码按失败处理，地址与 token 不会出现在错误信息里。
- 每日简报的模拟持仓改为按银行逐行估值并给合计。
- 每日简报默认把当前主显银行排在第一行；计算页有记录时追加模拟持仓、浮动盈亏、当日收益与已实现盈亏，统一按客户卖出价估值，缺少前一交易日收盘价时不硬算当日收益。
- 新增邮件推送（SMTP）：支持 465 SSL 与 587 STARTTLS，与系统通知、Bark、Webhook 并行，受免打扰时段约束；设置页提供测试按钮，口令只存本机。
- 新增每日简报：每天按时汇总最近一个已结束交易日的开/收/高/低与涨跌幅，同一天只发一次。
- 新增免打扰时段：时段内不弹通知、不发 Bark/Webhook/邮件，行情照常刷新。
- 新增通用 Webhook 推送（POST JSON），与 Bark、系统通知并行；Bark 与 Webhook 都有测试按钮。
- 修复长时间运行后的卡顿：分时图逐笔新建日期格式化器，导致每轮轮询分配上 GB 临时内存；采样库改为批量、限频写盘，并跳过时间戳和价格都没变的重复采样，存储文件明显变小。
- 休市期间取不到数据或返回空不再判为异常、不再发通知；开市后仍取不到才提醒。更新列的陈旧标记也改为按每家银行自己的交易时段判断。
- 移除建行监测：不再抓取建行账户金与积存金当日价，只保留京东代销的六家银行；旧配置里的建行提醒和排序会自动清理。
- Windows：修复点一下最大化/全屏后任务栏文字消失且再也不回来的问题。改成直接检测任务栏本身是否被盖住，最大化窗口不再误判；任务栏文字窗口异常时会自动重建。
- Windows：新增 `taskbar.log` 记录任务栏文字的每次隐藏原因，便于排查。

## 1.0.3

- Windows：修复退出全屏应用后任务栏文字偶发不恢复。
- Windows：悬浮球与任务栏文字改为按光标位置拖动，修复拖动卡顿、悬浮球跑向屏幕左上角的问题。
- Windows：安装/卸载时自动结束正在运行的应用。

## 1.0.2

- 新增面板均价计算器，支持买入/卖出记账、加权均价、持仓浮盈与已实现盈亏。
- macOS 安装包改为 ad-hoc 签名，避免下载后被系统判成“已损坏”。
- 安装包只保留中英文，dmg 换用 bzip2 压缩，体积减小约 7%–10%。
- Windows：安装/卸载不再询问“程序正在运行”。

## 1.0.0

- 首个公开版本：多银行积存金实时价、到价/涨跌幅提醒、Bark 推送、菜单栏/托盘/VS Code 三种形态、分时图、计算器。
