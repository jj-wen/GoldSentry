# 变更记录

## 1.0.3

- Windows：修复退出全屏应用后任务栏文字偶发不恢复。
- Windows：悬浮球与任务栏文字改为按光标位置拖动，修复拖动卡顿、悬浮球跑向屏幕左上角的问题。
- Windows：安装/卸载时自动结束正在运行的应用。

## 1.0.2

- 新增面板均价计算器，支持买入/卖出记账、加权均价、持仓浮盈与已实现盈亏。
- macOS 安装包改为 ad-hoc 签名，避免下载后被系统判成“已损坏”。
- 安装包只保留中英文，dmg 换用 bzip2 压缩，体积减小约 7%–10%。
- Windows：安装/卸载不再询问“程序正在运行”。

## 1.0.0

- 首个公开版本：多银行积存金实时价、到价/涨跌幅提醒、Bark 推送、菜单栏/托盘/VS Code 三种形态、分时图、计算器。
