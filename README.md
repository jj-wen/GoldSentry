# GoldSentry

监控多家银行**积存金**实时价，到价 / 涨跌幅提醒，多渠道推送。当前有 **Mac 菜单栏**、**Windows 托盘（含任务栏文字与悬浮球）** 和 **VS Code 状态栏** 三种形态。

> 行情来自公开渠道，仅供参考，不构成投资建议。

## 功能

- **多银行积存金实时价**：浙商、民生、工商、广发、兴业、中信。
- **三种形态**：macOS 菜单栏、Windows 托盘（含贴附任务栏的文字和可拖动悬浮球）、VS Code 状态栏。
- **详情悬浮**：鼠标停在详情表格任意一行，显示银行全名、费用、报价时间、交易时段和当前开闭市状态。
- **提醒与推送**：到价 / 当日涨跌幅 / 组合持仓盈亏提醒，穿越阈值才触发；支持系统通知、Bark、Webhook、邮件和飞书/钉钉/企业微信/Telegram 机器人推送，可设免打扰时段与每日收盘简报。简报固定把当前主显银行排第一，计算页有记录时还会按各家银行带上模拟持仓与当日收益。
- **显示可配**：品种名、涨跌箭头、涨跌幅百分比分别开关；Windows 任务栏文字和悬浮球可独立启停。
- **分时图**：面板分时曲线 + Windows 任务栏迷你走势，支持 30 分钟到 10 天多个范围。
- **均价计算器**：面板「计算」页按银行分别记账，按选中的买入算加权均价与总成本，按各行实时卖出价估算持仓浮盈；卖出按移动加权平均扣减成本并结算已实现盈亏，多银行持仓分开展示并给出合计。
- **刷新与自启**：刷新间隔 5 秒–10 分钟；支持开机自启。
- **休市健康态**：周末、法定节假日、节前停夜盘不误报“数据陈旧”，休市期间取不到数据也不会发异常通知。

## 下载与安装

安装包发布在本仓库的 [Releases](https://github.com/jj-wen/GoldSentry/releases)。

### macOS

- Apple Silicon（M1/M2/M3/M4）下载 `GoldSentry-1.0.4-arm64.dmg`；Intel 下载 `GoldSentry-1.0.4-x64.dmg`。
- 打开 dmg，把 **GoldSentry** 拖进「应用程序」文件夹，再从应用程序启动。
- 当前只有 ad-hoc 签名、未公证：首次启动请右键 → **打开**；若被系统拦截，去「系统设置 → 隐私与安全性」点 **仍要打开**。
- 如果提示“应用已损坏”（多见于从微信/AirDrop 传来的包），在终端执行：
  ```bash
  xattr -dr com.apple.quarantine /Applications/GoldSentry.app
  ```
- **开机自启**：先确保从「应用程序」启动，再到面板「设置 → 开机自启」勾选。如果直接从 dmg 挂载目录运行，开关会提示先拖进「应用程序」。

### Windows

- 安装版：`GoldSentry-Setup-1.0.4-x64.exe`，双击安装，可选安装目录。安装或卸载时会自动结束正在运行的 GoldSentry，不用先手动退出。
- 便携版：`GoldSentry-1.0.4-x64-portable.exe`，无需安装，双击运行。
- 未签名应用会触发 SmartScreen：点「更多信息 → 仍要运行」。如果系统启用了 **Smart App Control**，可能直接拦截未签名 exe，需要关闭 SAC 或使用代码签名证书。
- **开机自启**：面板「设置 → 开机自启」勾选。安装版注册安装后的 exe；便携版注册原始便携 exe 路径，不使用临时解压目录。

## 使用

- **macOS**：点菜单栏价格打开详情，右键打开设置。
- **Windows**：托盘左键=详情、右键=设置；任务栏文字和悬浮球遵循同样的左键/右键语义，任务栏文字可沿任务栏拖动，悬浮球可拖到任意位置、滚轮调透明度。
- **详情页**：点一行切换主显品种，长按一行拖动排序；鼠标悬停任意一行查看该银行费用、报价时间、交易时段和开闭市状态。
- **计算页**：选银行、买入/卖出、日期与克数单价即可记账；勾选记录看选中买入的均价，下方按每家银行的实时卖出价列出持仓与浮盈，并汇总合计。
- **设置页**：调刷新间隔、显示内容、分时图、Bark / Webhook / 邮件 / 机器人推送、每日简报、免打扰、开机自启；到价与组合盈亏提醒也在这一页维护。
- **VS Code**：状态栏价格左键看全部品种对比，旁边的齿轮进入设置。

## 开发

```bash
corepack enable pnpm
pnpm install
npm run menubar        # 启动 Mac 菜单栏 / Windows 托盘
npm run verify:all     # 不依赖界面的断言
```

更多命令见 `package.json` 的 scripts。
