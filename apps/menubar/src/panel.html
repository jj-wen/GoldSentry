Bark 推送到 iPhone

key 明文存在本机 userData/settings.json，不进仓库；自建 Bark 服务填自己的 https 地址。

Webhook 推送

POST JSON：{ title, body, source, ts }；地址里的 token 只存本机，错误信息不会回显完整地址。

机器人推送

飞书/钉钉/企业微信填自定义机器人地址；钉钉开加签时填密钥。Telegram 填 bot token 与 chat id。地址和 token 只存本机 userData/settings.json，错误信息不会回显。

邮件推送

465 端口勾 SSL；587 关闭 SSL 后自动 STARTTLS（服务器不支持时会拒绝发送，避免明文传口令）。账号与授权码只存本机 userData/settings.json；QQ/163 等要填授权码，不是登录密码。
